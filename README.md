## 요약

- **기간 안 최저가**: 참좋은여행 동유럽 3개국 7일(11/24~11/30, 아시아나), 4인 약 **917만 원**. 아동 요금이 성인과 같고 국적기입니다. 다만 아직 **출발확정 전**(예약 10명/최소 20명)이라 취소 가능성이 있고, 7일 일정이라 이탈리아 9일보다 관광 일수가 적습니다.
- **출발확정 + 관광지 최다**: 하나투어 이탈리아 완전일주 9일(11/22~11/30, 티웨이), 4인 약 **1,082만 원**. 출발확정, 잔여 5석, 10개 도시, 아동 요금 동일.
- **전체 최저 + 긴급모객(기간 1일 초과)**: 하나투어 동유럽 3국 9일(대한항공 직항, 11/23~12/1), 4인 약 **1,000만 원**.
- 국적기 + 9일을 원하면 하나투어 이탈리아 일주(대한항공, 기간 안) 4인 1,320만 원입니다.
